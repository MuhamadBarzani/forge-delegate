forge-delegate → install configurator

MCP server that lets your primary agent (Claude Code / Codex / opencode) delegate grunt work to cheaper models. Pick your options, then copy the one-line install command — or let your AI run it.

1 · Configure

Loading model catalog…

Model list & prices come from models.dev. The free opencode/* models it lists change fast and can be outdated (e.g. opencode/minimax-m3-free is no longer served); providers you auth with a key (deepseek, openai, …) are usually in sync. Either way, run opencode models before picking and copy a model from that list — it's exactly what your opencode accepts today, so the install command will work.

Free opencode/* models need no auth — zero setup. For any other provider (deepseek, openai, google, …), you must log it into your own opencode first: opencode auth login <provider>. forge-delegate reuses your opencode's credentials and never stores API keys.
